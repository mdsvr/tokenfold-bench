# TokenFold Bench

Three ways to feed a repository to a model, measured on the same question.

Measured on `django/django` (400 files indexed), asking *"how does password hashing
work and which algorithm is the default"*:

| strategy | tokens | projected cost | what the model can see |
|---|---:|---:|---|
| naive | 408,333 | $2.04 | all 400 files, complete source |
| retrieval | 40,032 | $0.20 | 11 files — **389 invisible** |
| folded | 40,000 | $0.20 | 8 full + 5 signatures + 387 names — **nothing dropped** |

The point is not naive vs. the rest. It is **retrieval vs. folded at an identical token
budget**: retrieval buys depth by going blind, folded keeps every file visible at some
resolution and spends what is left on depth.

Folded answers that question correctly — PBKDF2 / `pbkdf2_sha256`, 1,800,000 iterations,
128-bit salt entropy, citing `django/contrib/auth/hashers.py` — from 8 files out of 400.

## How it works

**Indexing is build-time, never at request time.** Repos are cloned shallow
(`git clone --depth=1`), symbol-extracted with per-language regex, token-counted once,
and committed as JSON under `data/`. A cold deploy serves the demo instantly and cannot
fail while someone is clicking it.

**Folding is three tiers, not top-k.** Every file contributes its symbol names to a
repo-wide skeleton, which is charged against the budget first. Whatever budget remains
is spent depth-first: full source for the strongest matches, signatures for their
neighbourhood. Nothing is ever fully invisible.

**Relevance is import-graph aware.** A file imported by a high scorer gets a share of
that score, so files that never mention the query terms still surface. Plain keyword or
vector retrieval structurally cannot do this.

## Two models, on purpose

- **Token counts** use the `o200k_base` BPE tokenizer as a stand-in for Claude's.
  Absolute counts land within a few percent; the naive:folded *ratio* — the actual
  claim — is essentially tokenizer-independent.
- **Dollar figures** are projected at `claude-opus-5` rates ($5/1M input), because that
  is the benchmark being reproduced.
- **Answers** are generated by `gemini-3.7-flash` on the free tier, so the demo can be
  clicked freely without a per-click bill. The UI labels which is which.

## Run

```bash
npm install
cp .env.example .env.local                   # add a key from aistudio.google.com/apikey
node scripts/index-repo.mjs django/django    # writes data/django__django.json
node scripts/check.ts                        # self-check on the strategies
npm run dev
```

`/api/compare` is free and instant — pure computation, no model call. `/api/ask` is the
only route that talks to a model, and naive is gated behind a confirm because one call
sends the entire repository.
